# Assignment: Problem Solving with TypeScript & OOP

## Overview

This repository contains my solutions for the TypeScript and OOP assignment (B8A1).

Through this assignment, I practiced different TypeScript concepts and tried to apply them in practical coding problems.

### What I Covered

- Basic types and optional parameters
- Union types and type narrowing
- Readonly tuples
- Generics and rest parameters
- Interfaces and object types
- `keyof` constraints
- Object-Oriented Programming (OOP)
- Access modifiers and inheritance
- Asynchronous programming with Promises
